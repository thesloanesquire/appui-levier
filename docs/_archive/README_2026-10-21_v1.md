# Levier : outil d'agence de recherche de fonds

**But** : piloter plusieurs campagnes de recherche de fonds auprès des fondations suisses. Pour chaque client, l'outil classe les fondations (en citant leur but statutaire), rédige une lettre sur mesure par fondation, suit les échéances, les validations, les envois et les relances. Il offre aussi un portail client en lecture.

**État au 21.10.2026** : prototype v0.2, local, sans serveur. Base réelle : 17'779 fondations actives du registre du commerce (LINDAS, open data OFJ), dont 14'980 retenues (sans prévoyance ni liquidation). Clients et demandes **fictifs de démonstration**. Matching et lettres par règles ; l'IA Infomaniak est prévue en phase 2.

## Lancer

```bash
cd "CONSULTING /Levier/src" && python3.12 -m http.server 8791
```
puis ouvrir http://localhost:8791. Raccourci : `⌘K` pour tout chercher. Réinitialiser la démo : console du navigateur, `LevierReset()`.

## Mettre à jour la base des fondations (13 s)

```bash
cd "CONSULTING /Levier/scripts" && python3.12 lindas_fondations.py
```
Produit `data/fondations_ch.json` / `.csv` (base complète) et `src/data/fondations.js` (application). Source à citer : « Registre du commerce (Zefix), OFJ, via LINDAS ».

## Bot IA : critères + recherche automatique des fondations

```bash
cd "CONSULTING /Levier/scripts" && python3.12 bot_fondations.py --url https://www.association.ch --nom "Nom" --canton VD --type association
```
1. lit le site du client ; 2. l'IA établit profil et critères (domaines, mots-clés FR/DE, zone, exclusions) ; 3. recherche dans les 14'980 fondations ; 4. l'IA évalue les 60 meilleures (score, raisons, risques, citation exacte du but vérifiée, angle de lettre). Le client et son classement apparaissent dans l'application (onglet Fondations, mode « Bot IA »), et les lettres reprennent la citation et l'angle.
- Moteur par défaut : CLI Claude (`claude` doit être connecté une fois : taper `claude` puis `/login`). Alternative : `--moteur infomaniak` avec `INFOMANIAK_TOKEN`, `INFOMANIAK_PRODUCT_ID` dans `Levier/.env`.
- Veille : `python3.12 bot_fondations.py --tous` relance tous les clients (après une mise à jour de la base).
- Données envoyées à l'IA : texte public du site du client et buts statutaires publics.
- Test du 21.10.2026 : `data/bot/ate-pedibus.md` (site public pedibus.ch, évaluation faite par Claude dans la session, 30 candidates, 30 citations vérifiées).

## Fiches pratiques des fondations (site, contact, délais, modalités)

```bash
cd "CONSULTING /Levier/scripts" && python3.12 enrichir_fondations.py --client ate-pedibus --top 10
```
Variantes : `--id <ehraid>`, `--nom "Fondation X"`, `--nouvelles` (fondations donatrices romandes apparues depuis la dernière extraction LINDAS). Moteur : CLI Claude avec recherche web, sources citées dans chaque fiche, fiche valable 90 jours (`--force` pour refaire). Exclus : local.ch, search.ch, Moneyhouse et autres annuaires dont les conditions interdisent l'extraction automatique ; aucune donnée personnelle, seulement des coordonnées institutionnelles.
